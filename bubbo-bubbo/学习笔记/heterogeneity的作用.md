这是一个关于概率计算的有趣问题！让我来详细解释为什么`_heterogeneity`值越大，气泡分布会越分散：

### _heterogeneity参数的核心作用

`_heterogeneity`（异质性）参数在气泡类型选择过程中扮演着**"基础随机性权重"**的角色。在代码中，它通过两个关键位置影响选择概率：

1. **初始总概率空间**：
   ```typescript
   let totalChance = boardConfig.bubbleTypes.length * this._heterogeneity;
   ```

2. **每种气泡类型的基础权重**：
   ```typescript
   const chancePerType = boardConfig.bubbleTypes.reduce(
       (map, b) => map.set(b, this._heterogeneity),
       new Map<BubbleType, number>(),
   );
   ```

### 为什么值越大越分散？

让我们用具体数值来举例说明：

#### 场景1：_heterogeneity = 0.5（较小值）
- 假设游戏中有4种气泡颜色
- 初始总概率空间 = 4 × 0.5 = 2
- 每种颜色的基础权重 = 0.5

如果一个位置有2个红色邻居气泡：
- 红色权重 = 0.5 + 2 = 2.5
- 其他颜色权重 = 0.5 各
- 总概率空间 = 2 + 2 = 4
- 红色被选中概率 = 2.5 ÷ 4 = 62.5%
- 其他颜色被选中概率 = 0.5 ÷ 4 = 12.5% 各

**结果**：邻居的影响非常大，容易形成聚集

#### 场景2：_heterogeneity = 5（较大值）
- 初始总概率空间 = 4 × 5 = 20
- 每种颜色的基础权重 = 5

同样有2个红色邻居气泡：
- 红色权重 = 5 + 2 = 7
- 其他颜色权重 = 5 各
- 总概率空间 = 20 + 2 = 22
- 红色被选中概率 = 7 ÷ 22 ≈ 31.8%
- 其他颜色被选中概率 = 5 ÷ 22 ≈ 22.7% 各

**结果**：邻居的影响相对变小，各种颜色都有相当的被选概率，气泡分布更分散

### 数学本质

`_heterogeneity`参数实际上**平衡了"基础随机性"和"邻居影响"**之间的权重：
- 当它较小时，邻居的影响（+1/个）占主导地位
- 当它较大时，基础随机性占主导地位，邻居的额外影响相对减弱

这正是游戏难度逐渐提升的机制 - 随着`_heterogeneity`值增加，玩家将越来越难找到大片相同颜色的气泡进行消除，需要更精准的瞄准和策略。
